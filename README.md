# La Cosa Es Simple · Página de ventas

Página de ventas del e-book «Leer a las Personas en 60 Segundos».

## Abrir la página

Abre `index.html` en el navegador. No requiere instalación ni compilación.

## Checkout

Los botones de compra enlazan a https://pay.hotmart.com/B105228709J.

## Contenido

- `index.html`: página completa con diseño adaptable a móvil.
- Plantilla gratuita de observación de 7 días, generada desde el botón de descarga de la página.

Este repositorio contiene la página de ventas. El e-book se entrega a través de Hotmart.

## Desplegar en Vercel

1. Importa el repositorio en Vercel.
2. Selecciona Other como Framework Preset.
3. Usa la raíz del repositorio como Root Directory.
4. No indiques comandos de instalación ni de compilación.
5. El directorio de salida es `.`. La configuración está en `vercel.json`.

La página es estática, sin dependencias ni variables de entorno. Vercel puede desplegar los cambios de la rama principal automáticamente al conectar el repositorio.
